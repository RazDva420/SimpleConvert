SimpleConvert 0.1 — конвертер файлов для Windows 10/11 x64

ЗАПУСК
Откройте SimpleConvert-minimal.exe. Установка не нужна. Сохраняйте ffmpeg.exe и
pdfium.dll в одной папке с программой. Интернет для работы не требуется.

КАК ПОЛЬЗОВАТЬСЯ
В окне только два списка «Из» / «В» и зона перетаскивания.
1. Оставьте «Авто» или выберите исходный и конечный форматы.
   Исходные форматы сгруппированы внутри списка.
2. Перетащите файлы в зону. Конвертация начнётся сразу, без кнопки запуска.
   Можно также нажать на зону и выбрать файлы через обычный диалог.
3. Надпись в зоне покажет ход работы и результат.
   При ошибке нажмите на зону для просмотра подробностей.

В режиме «Авто»: PDF → JPG, видео → MP3, PNG → JPG,
остальные изображения → PNG, MP3 → WAV, остальное аудио → MP3.
Если выбран конкретный формат «Из», файлы другого формата не принимаются.
Esc отменяет текущую конвертацию. Закрытие окна дожидается отмены.

Оригиналы не изменяются. Занятое имя получает суффикс «(1)», «(2)» и т. д.
Каждый файл сохраняется только после успешной конвертации. При отмене
незавершённый результат удаляется; ранее завершённые файлы сохраняются.
Для разных исходных папок результаты сохраняются каждый в свою папку.

ФОРМАТЫ
Изображения: JPG/JPEG, PNG, WebP, BMP, TIFF/TIF, GIF, ICO.
Результат: JPG, PNG, WebP, BMP, TIFF, GIF или PDF.
Анимация GIF/WebP и многостраничный TIFF: берётся первый кадр/страница.
Прозрачность при сохранении в JPG заменяется белым фоном.
Поворот изображения по EXIF учитывается. JPG: качество 92.

Документы: PDF → JPG/PNG (200 dpi, все страницы) или TXT.
Многостраничные PDF: имя_page_001.jpg, имя_page_002.jpg и т. д.
TXT извлекается из текстового слоя; OCR для сканов не включён.
Защищённые паролем PDF и Word/Excel/PowerPoint пока не поддерживаются.

Медиа, вход: MP4, MKV, MOV, AVI, WebM, M4V, WMV, MPEG/MPG, TS,
MP3, WAV, FLAC, AAC, OGG, M4A, Opus, WMA, AIFF.
Аудио, результат: MP3, WAV, FLAC, AAC, OGG.
Видео, результат: MP3/WAV/FLAC/AAC/OGG, MP4, MKV, WebM, GIF.
Для извлечения аудио в видео должна быть звуковая дорожка.
Берётся первая аудио/видеодорожка. MP4/MKV: H.264 + AAC; WebM: VP9 + Opus.
GIF из видео: 12 кадров/с, ширина 640 пикселей. Без DRM.
Фактическое чтение медиа проверяется FFmpeg при конвертации.

ИСХОДНЫЙ КОД
Папка source содержит Rust-код, Cargo.lock и проверки конвертации и окна.
Для сборки: Rust stable MSVC и Visual Studio C++ Build Tools / Windows SDK.
В папке source: cargo build --release --locked
Скопируйте target/release/simple-convert.exe на уровень выше как
SimpleConvert-minimal.exe. Для проверки: cargo test --locked
Тест использует ffmpeg.exe и pdfium.dll из папки над source.
Программа работает без установленных Rust, Python или .NET.

КОМПОНЕНТЫ
Интерфейс: egui/eframe. Изображения: image. PDF: PDFium / pdfium-render.
Медиа: отдельный процесс FFmpeg 7.1 essentials от gyan.dev, GPLv3.
FFmpeg включён из пакета imageio-ffmpeg 0.6.0 (PyPI).
Лицензии библиотек и исходного кода находятся в папке licenses.
Сведения об исходниках и сборке FFmpeg: licenses/FFmpeg-SOURCE.txt.
