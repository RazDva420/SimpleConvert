# SimpleConvert

Локальный конвертер для Windows: изображения, аудио и видео через FFmpeg, PDF в изображения страниц или текстовый слой. Файл можно перетащить в окно; результат сохраняется рядом с оригиналом без перезаписи занятого имени.

## Версия 0.1

Исходники Rust/egui находятся в `src`. Для сборки нужны Rust stable MSVC, C++ Build Tools и Windows SDK: `cargo test --locked`, затем `cargo build --release --locked`. Пользовательская поставка также требует `ffmpeg.exe` и `pdfium.dll`, которые в этот исходный репозиторий не включены.

OCR, Office-документы и защищённые паролем PDF не поддерживаются. Снимка рабочего окна пока нет; вместо него на сайте показан значок.

## Лицензии

Файл лицензии собственного кода не найден. У FFmpeg и PDFium отдельные условия распространения; публичный архив с бинарными файлами нужно собрать с их уведомлениями.
